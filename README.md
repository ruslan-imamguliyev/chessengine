# chessengine

Python chess engine project with neural search engines.

## C++ engine reimplementation

A full C++ reimplementation of Alpha-Beta and MCTS (TorchScript + pybind11 compatible) is provided in [`cpp_engine/`](cpp_engine).

See [`cpp_engine/README.md`](cpp_engine/README.md) for:

- compiler installation guidance (Linux + Windows),
- CMake build guide,
- pybind11 integration,
- project integration examples.
